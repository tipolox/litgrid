DOM click timers exclude physical input-device latency and compositor paint.

Source and packaged behavior checks cover programmatic selection, real keyboard selection/navigation, stable keys through replacement/sort/filter/page changes, duplicate/missing/invalid identity rejection, same-reference mutation, scope clearing and external stale-response guards.
