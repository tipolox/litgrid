# LitGrid Playground

An interactive Vite + React development playground for exploring, verifying, and testing LitGrid features across high-volume datasets, column resizing, sorting, filtering, quick search, pagination, theming, and selection modes.

## Getting Started

From the workspace root:

```bash
pnpm install
pnpm dev
```

Or from the `apps/playground` directory:

```bash
pnpm dev
```

Open the displayed local development URL (typically `http://localhost:5173`) in your browser.

## Build

To verify that the playground builds for production:

```bash
pnpm build
```
